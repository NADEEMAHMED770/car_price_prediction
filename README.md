# 🚗 Car Price Prediction using Multiple Linear Regression

## Overview

This project uses Multiple Linear Regression to predict the selling price of used cars based on features such as:

* Year
* Present Price
* Driven Kilometers
* Fuel Type
* Selling Type
* Transmission

The project demonstrates a complete machine learning workflow, including data preprocessing, feature engineering, model training, prediction, and evaluation.

* Python

## Machine Learning Workflow

### Data Cleaning

* Removed duplicate records
* Dropped unnecessary columns
* Checked missing values

### Feature Engineering

* Encoded Selling Type
* Encoded Transmission
* One-Hot Encoded Fuel Type

### Model Development

* Train-Test Split
* Multiple Linear Regression
* Predictions on Test Data

### Model Evaluation

* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)
* Root Mean Squared Error (RMSE)
* R² Score

---

## Results

The model achieved an R² Score of approximately 0.90 on the test dataset.
